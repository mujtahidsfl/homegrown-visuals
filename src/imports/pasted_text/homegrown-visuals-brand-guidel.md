05 — Buttons & CTAs
Button System
Every button has a specific role. Never use two Primary buttons side-by-side in the same section — it destroys visual hierarchy.
Button	Preview Style	Role	When to Use
Primary Action	PRIMARY	Primary Action	The single most important CTA per section. Use once per section only.
Secondary Action	VIEW SERVICES	Secondary Action	Supporting CTAs, service links, secondary page actions.
Accent / Badge	MOST POPULAR	Accent / Badge	Featured package highlight, promotional callouts. Use rarely.
Outline — Light BG	LEARN MORE	Outline — Light BG	On off-white/light backgrounds where solid fill is too heavy.
Outline — Teal	GET A QUOTE	Outline — Teal	Teal outline variant for lighter sections.
Ghost / Text	VIEW GALLERY →	Ghost / Text	Tertiary text-level actions, nav links, inline links.

CTA Hierarchy Rule
Each section/page should have a maximum of 1 Primary (Dark Blue) button.
Secondary and Outline buttons support it as second/third actions.
On dark backgrounds, use the Teal (Secondary) button as the main CTA.
Never place Primary next to Primary — it eliminates the visual hierarchy.

09 — Usage Rules
Do’s & Don’ts
Quick reference rules to keep the brand consistent across every page of the site.
Category	Rule	
Color	Always use Off-White (#F4F6F7) as the page background, never pure white	DO
Color	Use pure black (#000000) anywhere on the site	DON'T
Color	Use Teal (#2FA4A9) for all interactive elements, links, and hover underlines	DO
Color	Use Sand (#D2A679) as a background for large full-page sections	DON'T
Typography	Only use PP Neue Montreal (headings) + Satoshi (body) — no system fonts like Arial	DO
Typography	Use more than 3 font sizes in a single section	DON'T
Typography	Montserrat Bold is the primary brand font per client spec — use for logo lockups	DO
Buttons	Use ALL-CAPS text + 0.06em letter spacing on every button	DO
Buttons	Place two Primary (Dark Blue) buttons side by side in the same content block	DON'T
Spacing	Only use values from the spacing scale (4, 8, 12, 16, 24, 32, 48, 64, 80, 120px)	DO
Spacing	Use arbitrary values like 11px, 19px, 37px for gaps or padding	DON'T
Images	Apply a subtle Dark Blue overlay (15–25% opacity) on hero images to improve text legibility	DO
Images	Place text directly on bright/busy photos with no overlay — it will be illegible	DON'T
Radius	Use pill (999px) radius for all buttons and section labels	DO
Radius	Use sharp 0px corners on interactive elements like buttons	DON'T
Sections	Always precede H2 headings with a small Teal uppercase section label	DO
